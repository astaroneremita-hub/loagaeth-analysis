# The name dynasties of the Loagaeth

**#344.** Os 90 nomes formam **famílias genealógicas** reais (grafo edição-1: 55 arestas,
null 0.1, **z=+229.6** — o acaso nunca liga dois). Há **dez casas** (uma por raiz) e duas
grandes — **NOCHA** e **CHASTOR** — que se **casam** no composto **NOCHASTOR**. Um quarto
dos nomes (24) fica fora das casas: a camada "plebeia".

## O casamento das casas (pontes)

7 nomes carregam **duas** raízes = fusão de dinastias. Quase todos **NOCHA + CHASTOR**:

```
NOCHA + CHASTOR  →  NOCHASTOR  (NO·CHA·STOR, fundidos na sílaba CHA)
                    nochastor, nochastora, nochastorad, nochastoral,
                    anochastor, axnochastor
CHADAX + NOCHA   →  nochadaxa
```

O NOCHASTOR vira **linhagem própria** (família de 8: + nechastor/a, ...). As duas maiores
casas se juntam no nome central do livro.

## Como derivam (acreção de afixo)

```
adnocha → adnochap → adnochaph → adnochapha        (sufixo cresce letra a letra)
chastor → chastora → chastorad / chastoral / chastoran   (ramos de sufixo)
chastor → ichastor → ichastora ; zichastor → zichastora  (prefixo I-/ZI- = linhas paralelas)
nocha   → nochap → nochaph                          (mesma coluna de sufixo)
```

Famílias edição-1 (componentes do grafo): CHASTOR(10), NACHO(8), NOCHASTOR(8), CHADAX(6),
ADNOCHA(6), ANTANTOX(3), NOCHA(3)… + 34 nomes isolados.

## Leitura honesta

- **Estrutura de família é real e fortíssima.** z=+229.6: nomes aleatórios do mesmo
  tamanho/letras praticamente nunca ficam a 1 edição um do outro; estes ficam (55 vezes).
  Confirma que o campo de nomes é **gerado por derivação** (prefixo·raiz·sufixo, #335), não
  solto.
- **Sim, há dinastias além de CHASTOR.** NOCHA é a maior; NACHO, CHADAX, GETH, ACLAX são
  casas médias. CHASTOR não é única — é uma de duas cabeças.
- **O evento central é o casamento NOCHA×CHASTOR** (→ NOCHASTOR), que domina a diagonal
  26a (#343) e o miolo do livro (#342).
- **24 nomes (27%) sem raiz** = camada fora das casas (gasta, nadab, ronzin, zidnopha…).
  Reais (aparecem no livro e nas diagonais) mas não derivam das 10 raízes — nomes curtos/
  avulsos. Não force raiz neles.
